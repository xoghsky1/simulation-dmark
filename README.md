# 디마크 술자리 🍶

당산 디마크 거실에서 친구들이랑 소주 마시는 3D 멀티플레이 시뮬레이터.
링크만 열면 폰/PC 브라우저에서 바로 입장 (설치·로그인 없음, 최대 20명).

- 3D: Three.js (CDN), 실시간: Supabase Realtime (broadcast + presence)
- 조작: PC WASD/드래그/휠, 폰 조이스틱/드래그/핀치, 바닥 탭 → 이동, 방석 탭 → 앉기
- 액션: 🍶 따르기 · 🥂 짠 · 🥃 원샷 · 채팅
- `?room=이름` 붙이면 다른 방으로 분리
